# Gemini CLI Quick Start

To use the Gemini CLI in this project, simply run the following command in your terminal:

```bash
gemini -m gemini-3.1-pro-preview
```

This will start an interactive session with the `gemini-3.1-pro-preview` model.

## Common Flags
- `--include-directories <dir>`: Include project files in the context.
- `--resume`: Resume your last session.
- `-h`: Show all help options.
