# Environment Variables

Dokumentasi dari semua environment variable yang digunakan dalam aplikasi ini.

| Variable Name          | Description          | Example         | Required |
| ---------------------- | -------------------- | --------------- | -------- |
| VITE_DEV_PASSWORD      | Development password | dev             | No       |
| VITE_SENTRY_AUTH_TOKEN | Sentry auth token    | token           | No       |
| VITE_SENTRY_DSN        | Sentry DSN           | https://d@o.s/p | No       |
| VITE_SENTRY_ORG        | Sentry organization  | my-org          | No       |
| VITE_SENTRY_PROJECT    | Sentry project       | my-project      | No       |
| VITE_SUPABASE_ANON_KEY | Supabase anon key    | ey...           | Yes      |
| VITE_SUPABASE_URL      | Supabase URL         | https://...     | Yes      |
| VITE_VAPID_PUBLIC_KEY  | VAPID public key     | B...            | No       |
