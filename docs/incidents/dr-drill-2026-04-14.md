# Laporan Simulasi Disaster Recovery (DR Drill)

**Tanggal Pelaksanaan**: 14 April 2026
**Tim**: SRE & Database Engineering
**Sistem Teruji**: Supabase Database Backup & Restore

## 1. Tujuan Simulasi

- Memverifikasi fungsionalitas Point-in-Time Recovery (PITR) pada Supabase.
- Mengukur RTO (Recovery Time Objective) untuk proses restore database ke environment staging baru.
- Memastikan integritas data post-restore (termasuk skema, RLS, dan user data).

## 2. Skenario Simulasi

Skenario yang diuji adalah simulasi kerusakan data parsial pada tabel `quiz_attempts` akibat human error, sehingga memerlukan restore database dari snapshot 1 jam sebelum insiden simulasi.

## 3. Langkah Pelaksanaan

1. **09:00 WIB** - Membuat snapshot / penanda waktu untuk target PITR.
2. **09:15 WIB** - Mengubah data secara sengaja (simulasi data corruption) pada `quiz_attempts`.
3. **09:20 WIB** - Tim On-call menerima "alert" simulasi dan mengidentifikasi anomali.
4. **09:30 WIB** - Memulai proses restore ke _new project_ (Staging Clone) via Supabase Dashboard memilih titik waktu 09:00 WIB.
5. **09:45 WIB** - Proses provisioning Staging Clone selesai.
6. **09:50 WIB** - Menjalankan script validasi integritas data dan verifikasi data `quiz_attempts` kembali ke state awal.
7. **10:00 WIB** - Uji coba aplikasi frontend dengan environment variabel mengarah ke Staging Clone (berhasil tanpa error).
8. **10:15 WIB** - Staging Clone dihapus, simulasi dinyatakan selesai.

## 4. Hasil dan Evaluasi

- **Recovery Point (RPO)**: Berhasil mengembalikan data persis pada 09:00 WIB.
- **Recovery Time (RTO)**: 45 menit (dari deteksi hingga aplikasi kembali normal pada Staging Clone). Jauh di bawah target RTO 4 jam.
- **Integritas Data**: 100% data valid, RLS policies tetap berfungsi, dan relasi antar tabel (Foreign Keys) tidak ada yang rusak.

## 5. Kesimpulan & Tindak Lanjut

Proses backup dan restore via PITR Supabase berjalan dengan sangat baik dan memenuhi standar SLO/SLA perusahaan. Tidak ada _action items_ kritis yang perlu segera diperbaiki, namun tim sepakat untuk terus melakukan drill rutin setiap bulan sesuai jadwal.
