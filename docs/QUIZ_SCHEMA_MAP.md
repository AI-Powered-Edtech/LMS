# Quiz Schema Map

> Generated by project analysis on 2026-03-31

## Core Tables

| Table              | Purpose                   | Notes                                     |
| ------------------ | ------------------------- | ----------------------------------------- |
| `quizzes`          | Quiz definitions          | Main quiz metadata                        |
| `quiz_questions`   | Question bank             | ⚠️ Column is `.text` NOT `.question_text` |
| `quiz_options`     | Answer options for MCQ    | Linked to quiz_questions                  |
| `quiz_assignments` | Quiz-to-course assignment | Links quizzes to courses/modules          |

## Attempts (v2 — Active)

| Table                       | Purpose                        | Notes                      |
| --------------------------- | ------------------------------ | -------------------------- |
| `quiz_attempts_v2`          | Main attempts table            | **Partitioned by month**   |
| `quiz_attempts_v2_2026_03`  | Partition: March 2026          |                            |
| `quiz_attempts_v2_2026_04`  | Partition: April 2026          |                            |
| `quiz_attempts_v2_2026_07`  | Partition: July 2026           |                            |
| `quiz_attempts_v2_2026_10`  | Partition: October 2026        |                            |
| `quiz_attempts_v2_historic` | Partition: older data          |                            |
| `quiz_attempt_questions_v2` | Per-question responses         | Linked to quiz_attempts_v2 |
| `quiz_a_q_v2_*`             | Partitioned question responses | Mirror partitions          |

## Attempts (Legacy)

| Table                           | Purpose                    | Notes                          |
| ------------------------------- | -------------------------- | ------------------------------ |
| `quiz_attempts_legacy`          | Old attempts table         | Read-only, data migrated to v2 |
| `quiz_attempt_questions_legacy` | Old per-question responses | Read-only                      |

## Supporting Tables

| Table                    | Purpose                        | Notes                  |
| ------------------------ | ------------------------------ | ---------------------- |
| `quiz_answers`           | Answer definitions             |                        |
| `quiz_answer_history`    | Answer change log              |                        |
| `quiz_attempt_telemetry` | Timing, focus events           | Performance monitoring |
| `quiz_cheating_events`   | Tab switches, copy-paste flags | Anti-cheat system      |
| `quiz_submission_queue`  | Async grading queue            |                        |
| `quiz_stats`             | Aggregated stats               | Cached metrics         |

## Relationships

```
quizzes ──┬── quiz_questions ──── quiz_options
          ├── quiz_assignments
          └── quiz_attempts_v2 (partitioned)
                    ├── quiz_attempt_questions_v2 (partitioned)
                    ├── quiz_attempt_telemetry
                    └── quiz_cheating_events
```

## Partitioning Strategy

`quiz_attempts_v2` uses **monthly range partitioning**. New partitions must be created before each month. Current partitions: 2026-03, 2026-04, 2026-07, 2026-10, historic.
