## 1. CSP Fix — Remove `unsafe-inline` + `unsafe-eval`

**Problem:** Content Security Policy menggunakan `unsafe-inline` dan `unsafe-eval`, melemahkan protection against XSS.

**Files to check/modify:**

- `vite.config.ts` — CSP header definition (dev server middleware)
- `index.html` — meta CSP tag (jika ada)

**Implementation steps:**

1. Generate nonce per-request di server (atau per-build di Vite)
2. Replace `unsafe-inline` dengan nonce-based: `'self' 'nonce-{random}'`
3. Replace `unsafe-eval` — pastikan tidak ada `eval()` atau `new Function()` di codebase
   - Cek apakah Supabase client / React Query / library lain butuh `eval`
   - Kalau iya, perlu approach berbeda (hash-based CSP atau whitelist domain)
4. Test: buka app, cek console untuk CSP violation errors

**Risk:** Medium — bisa break runtime kalau ada library yang pakai eval secara internal (e.g., Supabase, Vite HMR)

## 2. `@` Alias Fix — Point ke `src/` bukan project root

**Problem:** `@` alias di tsconfig mengarah ke project root, jadi import path jadi `@/src/features/...` instead of `@/features/...`

**Files to modify:**

- `tsconfig.json` — `compilerOptions.paths`
- `vite.config.ts` — `resolve.alias`

**Implementation steps:**

1. Update `tsconfig.json`:
   ```json
   "paths": {
     "@/*": ["src/*"]
   }
   ```
2. Update `vite.config.ts`:
   ```ts
   resolve: {
     alias: { '@': path.resolve(__dirname, 'src') }
   }
   ```
3. Find & replace all imports:
   - `@/src/` → `@/` (batch replace di seluruh codebase)
   - Cek: `grep -r '@/src/' src/ | wc -l` untuk tau berapa file
4. Run `pnpm typecheck` untuk verify tidak ada broken imports

**Risk:** Low — straightforward find & replace

## 4. Edge Functions Shared Helpers

**Problem:** Setiap edge function punya duplicate CORS headers, auth helpers, response wrappers.

**Target files:**

- `supabase/functions/_shared/cors.ts` — SUDAH DIBUAT (CORS headers + OPTIONS handler)
- Masih perlu: `auth.ts`, `response.ts`

**Implementation steps:**

### a. Create `supabase/functions/_shared/auth.ts`

```ts
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2'

export async function authenticate(req: Request) {
  const authHeader = req.headers.get('Authorization')
  if (!authHeader) throw new Error('AUTH_MISSING')

  const supabase = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_ANON_KEY')!, {
    global: { headers: { Authorization: authHeader } },
  })

  const {
    data: { user },
    error,
  } = await supabase.auth.getUser()
  if (error || !user) throw new Error('AUTH_INVALID')

  return { supabase, user }
}
```

### b. Create `supabase/functions/_shared/response.ts`

```ts
import { corsHeaders } from './cors.ts'

export function jsonResponse(data: unknown, status = 200) {
  return new Response(JSON.stringify(data), {
    headers: { ...corsHeaders, 'Content-Type': 'application/json' },
    status,
  })
}

export function errorResponse(message: string, status = 500) {
  return jsonResponse({ error: message }, status)
}
```

### c. Refactor 2-3 edge functions

- Pick functions yang paling banyak duplicate code (e.g., `ai-grade-essay`, `generate-ai-content`)
- Replace inline CORS/auth/response dengan import dari `_shared/`
- Test: deploy edge function, verify masih jalan

**Risk:** Low — additive changes, tidak mengubah existing behavior
