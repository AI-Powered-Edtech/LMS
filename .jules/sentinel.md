## 2024-04-11 - Prevent XSS and Open Redirect in window.location.assign
**Vulnerability:** The `GlobalSearchModal` component directly assigned an unsanitized URL from search results to `window.location.assign(url)`, opening up potential Cross-Site Scripting (XSS) via `javascript:` or `data:` URIs, or Open Redirect vulnerabilities if the API ever returned a malicious link.
**Learning:** Even when links are assumed to come from a trusted backend search API, defense-in-depth requires validating the URL before redirecting. The project already has a `sanitizeRedirectTarget` helper for this purpose.
**Prevention:** Always use `sanitizeRedirectTarget` from `authFlow.ts` before setting `window.location.href` or `window.location.assign()`. Since `sanitizeRedirectTarget` returns `null` for unsafe URLs, handle the `null` case explicitly by falling back to a safe route like `/app`, rather than using `?? url` which would silently execute the malicious input.
