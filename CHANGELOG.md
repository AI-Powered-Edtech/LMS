## [1.0.0] — TBD (pre-launch)

### Added
- Multi-tenant LMS frontend (React 19, Vite 6)
- VIL Rust backend (rate-limit, brute-force protection, JWT auth)
- PWA support (offline, install prompt, update toast)
- Role-based routes: student, teacher, admin, parent, principal
- AI features: quiz generator, tutor, course builder copilot
- Gamification: XP, badges, leaderboard, streak counter
- Gradebook, assignments, quizzes, peer review, attendance
- Privacy policy, terms of service, data export, account deletion
- Sentry crash reporting (frontend + backend)
- Playwright QA harness (80+ routes, 5 personas)
